# 召唤工作台 (Summon Workbench)

B站评论区"召唤魔法"工具：按话题标签批量收集同好观众名单，在你的目标视频评论区逐条发布带 @ 的召唤评论（每条10人、间隔可调、断点续跑）。

> ⚠️ **免责声明**：本工具模拟人工操作，但仍属自动化行为，使用有账号风控/封禁风险，请自行评估、节制使用。评论文案内置「回复 111 永久退订」机制，请务必尊重退订者。

## 功能一览

- 👤 **多账号扫码登录**：首次启动自动引导扫码；支持多账号添加 / 切换 / 退出；登录凭据只保存本机
- 📦 **多仓库**：每个仓库 = 独立名单队列 + 独立目标视频 + 独立探测标签，随时切换互不干扰
- 🏷️ **标签探测**：按B站话题标签搜索相关视频、爬取评论区用户，自动去重入库（排除已@ / 退订者 / 自己）
- 📝 **自定义话语**：召唤文案模板，🟡【艾特区】可挪动位置、{token} 自动计数、一键应用到未发队列
- ▶ **发送引擎**：真实键鼠操作 + 拟人节奏（间隔可调、随机抖动），断点续跑、失败自动重试
- 🖥️ **界面自适应**：任意窗口缩放文字不消失；右上角实时显示 CPU / 运存 / GPU 占用
- 🌐 **目标页一键打开**：在引擎专用的调试浏览器中打开 / 置前目标视频页
- 🔒 **单实例 + 窗口尺寸记忆**：重复点图标只调出已开窗口；记住你上次关闭时的窗口大小

## 快速开始（Windows）

1. 安装 [Python 3.8+](https://www.python.org/downloads/)（安装时勾选 **Add Python to PATH**）
2. 在项目目录打开命令行，执行：
   ```
   pip install -r requirements.txt
   ```
3. 双击 `run.bat` —— 首次会自动生成空白数据并打开工作台
4. 首次启动会弹出引导：用**B站手机App**扫码登录**你自己的账号**（凭据只存本机）
5. 点【＋ 新建仓库】→ 填仓库名和你的目标视频链接 → 创建
6. 在标签页填话题名 → 点【🚀 探测此标签】收集名单（或手工准备 `top5_queue.json`，10人/组）
7. 点【▶ 开始发送】——引擎会自动拉起专用浏览器并开始召唤

## 文件说明

| 文件 | 用途 |
|---|---|
| `workbench.py` | 主程序（GUI） |
| `top8_slow.py` | 发送引擎（由主程序自动拉起） |
| `cdp.py` | 浏览器自动化驱动 |
| `init.py` | 首跑生成空白数据模板（run.bat 自动执行） |
| `run.bat` | 一键启动 |
| `push.bat` | 一键推送更新到 GitHub |

## 隐私与安全

所有登录凭据（SESSDATA 等）与名单数据**只保存在你自己的电脑里**。
`.gitignore` 已排除这些文件——**永远不要把它们上传或发给任何人**。

## 更新到 GitHub

双击 `push.bat`：
- 第一次会要求你粘贴 GitHub 仓库地址（先在网页上创建一个**空的**仓库，建议选 Private）
- 首次推送时浏览器会弹出 GitHub 登录窗口，登录授权一次后凭据会被记住
- 之后每次更新只需双击 `push.bat`
